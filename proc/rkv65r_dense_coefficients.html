module procedure rkv65r_dense_coefficients pure module subroutine rkv65r_dense_coefficients(me, b, form)

Dense output for Verner's "most robust" 6(5) method rkv65r. This is the interpolant of order 6 (bi6) from the coefficient file, which requires 3 additional function evaluations (see rkv65r_dense_extra_stages).

Note

The interpolant is published in the polynomial form. Here it has been converted (exactly, using high precision arithmetic) to the form used in DOPRI5 and DOP853 (see dense_coefficients), which has much smaller roundoff error for these coefficients. This code is generated by scripts/generate_dense.py.
