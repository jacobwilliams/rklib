rk_class_stop rklib_module Subroutine

User-callable method to stop the integration (e.g., from f, g, or report). No further function evaluations are done, and the integrator returns, with the status set to RKLIB_ERROR_USER_STOPPED. This is not treated as an error (i.e., it does not stop the program if stop_on_errors is true).

set_fsal_cache rklib_module Subroutine

Compute the function and add it to the function evaluation cache, so that it can be reused by the next step (see check_fsal_cache). This is used for f at the end of a step: by the first-same-as-last (FSAL) methods (the last stage of the step), and by the methods whose dense output needs it as one of its extra stages (see dense_extra_stages).
